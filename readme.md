# Basic JavaScript named function demos
This repo holds five example of basic JavaScript functions

1. **fn-type1.js** illustrates a function with no parameters and no return value
2. **fn-type2.js** illustrates a function with parameters but no return value
3. **fn-type3.js** illustrates a function with no parameters but does have a return value
4. **fn-type4.js** illustrates a function with parameters and a return value
5. **fn-within-fn.js** illustrates a function which calls a helper-function
